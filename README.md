# homebrew-til

Homebrew tap for [til](https://github.com/kfet/til) — kfet's "Today I
Learned" notes packaged as [Agent Skills](https://agentskills.io/specification),
with a small CLI for listing, searching, showing, and validating them.

## Install (macOS & Linuxbrew)

```sh
brew install kfet/til/til
```

Or tap explicitly:

```sh
brew tap kfet/til
brew install til
```

## Upgrade

```sh
brew upgrade til
```

The formula bundles a snapshot of the `skills/` tree and points `til` at
that snapshot by default, so `til list`, `til search`, and `til show`
work out of the box without cloning the repo. To override the location
(e.g. to point at a working clone) set `TIL_REPO_PATH` or run
`til config <path>`.

## Not using Homebrew?

For the install script, source builds, and everything else, see the main repo:
**[github.com/kfet/til](https://github.com/kfet/til)**.

## How this tap is maintained

`Formula/til.rb` is auto-generated by the release workflow in
[`kfet/til`](https://github.com/kfet/til) on every tagged release, from
[`homebrew/til.rb.template`](https://github.com/kfet/til/blob/main/homebrew/til.rb.template)
with the version substituted in. Don't edit it here by hand — your
changes will be overwritten on the next release.
